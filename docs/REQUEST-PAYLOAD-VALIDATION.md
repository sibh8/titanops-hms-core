# TITANOPS-111: Request Payload Validation Across REST Controllers

## 1. Executive Summary & Input Sanitization
Web APIs that lack strict request payload validation allow malformed, oversized, or malicious inputs to penetrate downstream service and database layers, exposing systems to SQL injection, buffer overflows, and corrupted application states (violating **OWASP Top 10 - A03:2021 Injection** and **A04:2021 Insecure Design**).

Prior to **TITANOPS-111**, controllers used ad-hoc null/length checks or accepted unvalidated payloads, resulting in unhandled 500 Internal Server Errors or silent bad writes.

---

## 2. Technical Implementation

### A. Bean Validation Starter & Entity Constraints
Integrated `spring-boot-starter-validation` (Hibernate Validator 6.2.3.Final) into `user-service/pom.xml`.
Annotated `User.java` and `LoginRequest.java` with JSR-380 Bean Validation constraints:
* `@NotBlank(message = "Username cannot be blank")`
* `@Size(min = 3, max = 50, message = "Username must be between 3 and 50 characters")`
* `@NotBlank(message = "Password cannot be blank")`
* `@Size(min = 6, max = 100, message = "Password must be at least 6 characters")`
* `@Pattern(regexp = "^(STAFF|ADMIN|NURSE|DOCTOR|PHARMACIST|BILLING)?$", message = "Role must be one of allowed values")`

### B. Global Exception Handling & Structured HTTP 400 Responses
Implemented `GlobalExceptionHandler.java`:
* Intercepts `MethodArgumentNotValidException` generated by Spring MVC when `@Valid` checks fail.
* Extracts field-level errors into a structured error dictionary:
```json
{
  "timestamp": "2026-10-29T02:09:38.740Z",
  "status": 400,
  "error": "Bad Request",
  "message": "Validation failed for request payload",
  "errors": {
    "username": "Username must be between 3 and 50 characters",
    "password": "Password must be at least 6 characters"
  }
}
```

### C. Controller Enforcement
Annotated all REST write endpoints (`POST /api/auth/register`, `POST /api/auth/login`, `POST /api/users`, `PUT /api/users/{id}`) with `@Valid @RequestBody`.
